# Support

This repository contains sample/reference code and is not a first-party
Microsoft product. It is provided as-is and should be tested in a non-production
environment.

Use GitHub Issues for reproducible defects and feature requests. Include the
Python version, package versions, application status, and sanitized error text.
Do not include access tokens, credentials, customer workbooks, tenant URLs,
Dataverse record identifiers, or files from `execution_records/`.
