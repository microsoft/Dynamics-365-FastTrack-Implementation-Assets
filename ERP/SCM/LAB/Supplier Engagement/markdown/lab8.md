# Lab 8 of 9 — RFQ via Supplier Portal — TX-500 PCB Connector Sourcing

*⏱ ~45 min · Document Processing*

Technova issues a Request for Quotation for 500 M12 PCB Connectors. Alex creates the RFQ in SCM and sends it to Pacific Components Ltd. Maria views the RFQ in the supplier portal and submits a competitive bid. Alex reviews the bid in SCM and awards the RFQ to Pacific Components, completing the sourcing event end-to-end.

### Before you start
- [ ] Labs 5–6 complete — Pacific Components Ltd. (GV-001) is **Approved** in the Supplier Engagement app and has been **released to USMF** as a local vendor with **Collaboration activation = Active**. If not done, complete the *Setup* step below.
- [ ] Item `PCB-CON-M12` exists as a released product in USMF with site `1` / warehouse `11` configured. **This item is not part of standard USMF demo data** — create it first using the one-time *Setup* step below.
- [ ] Maria Santos can sign in to the supplier portal.

> **Lab variable:** The examples use `USSEP-0002` for the Pacific Components local vendor account. If your environment assigns or requires a different vendor number, use your actual value anywhere the labs reference `USSEP-0002`, including Lab 9.

## Setup A — Approve & release Pacific Components to USMF (one-time)

### Step 0a — Approve Pacific Components and release to USMF
Lab 5 ends with Pacific Components at *Qualified* status. Before Lab 8, the vendor must be **Approved** and released to USMF so it appears on the RFQ solicitation list. Skip this step if already done (local vendor `USSEP-0002` exists in USMF).

**1. Approve the global vendor**
**Where:** Supplier Engagement app › General › Global vendors › Pacific Components Ltd.

On the command bar click **Approve**. Enter a comment if prompted. Status changes to `Approved`.

**2. Release to USMF**
**Where:** Procurement and sourcing › Vendors › Supplier Engagement › All global vendors › Pacific Components Ltd.

Open the **Vendors** (Released vendors) tab. Click **New**. In the new-vendor row/dialog, set:

| Field | Value |
|---|---|
| Company | `USMF` |
| Vendor group | `10` |
| Currency | `USD` |

Save. Note the auto-assigned **Vendor account** number. The value is generated by your environment's number sequence; examples in this lab use `USSEP-0002` only as a placeholder.

**3. Enable Collaboration activation**
**Where:** Accounts payable › Vendors › All vendors › your assigned vendor account

On the **General** tab, set **Collaboration activation** = `Active`. Save.

> ✅ **Result:** Pacific Components Ltd. local vendor USSEP-0002 is active in USMF and enabled for supplier portal collaboration.

## Setup B — Create the PCB-CON-M12 released product (one-time)

### Step 0 — Create PCB-CON-M12 as a released product
**PCB-CON-M12 is not in the standard USMF demo data**, so create it once before running the RFQ. Skip this step if you have already created it (or if you substitute an existing USMF item such as `A0001` throughout Labs 8–9).

**Where:** Product information management › Products › Released products › + New

In the **New released product** dialog, enter (values below are valid in USMF — matched to a comparable stocked item):

| Field | Value | Notes |
|---|---|---|
| Product number | `PCB-CON-M12` | Required. |
| Product name | `M12 PCB Connector` | Required. |
| Product type | `Item` | Stocked physical part. |
| Product subtype | `Product` | Not a product master (no variants). |
| Item model group | `FIFO` | Lookup. |
| Item group | `Audio` | Lookup — select `Audio` for ledger posting. |
| Storage dimension group | `SiteWH` | Includes *Site* and *Warehouse* — needed for site 1 / warehouse 11. Use `SiteWH` (standard); `Ware` is WMS-specific and requires WMS activation. |
| Tracking dimension group | `None` | No batch/serial tracking. |
| Inventory / Purchase / Sales unit | `ea` | Same unit across all three. |

Click **OK** to create the product. Then open the released product and set the following so the RFQ/PO lines default correctly:
- **Default order settings** (Plan tab / Action Pane) — set default **Site = 1** and **Warehouse = 11** for Purchase orders.
- **Purchase price** (Purchase tab → *Purchase prices*, optional) — e.g., `2.50` USD, so a default cost is available before the awarded bid (USD 2.45) overrides it.

> ✅ **Result:** PCB-CON-M12 exists as a released product in USMF and can be transacted at site 1 / warehouse 11.

## Part A — Create & Send RFQ (Alex in SCM)

### Step 1 — Create a new Request for Quotation
**Where:** Procurement and sourcing › Requests for quotations › All requests for quotations › + New

The **New request for quotation** dialog opens. Fill in the fields (the RFQ case number is auto-assigned):

| Field (exact label) | Value |
|---|---|
| Purchase type | `Purchase order` |
| Document title | `TX-500 Program — M12 PCB Connector Sourcing Event` |
| Requested receipt date | `2026-09-15` *\** |
| Expiration date and time | `2026-08-15` *\* (bidding deadline)* |
| Site *(under Delivery address → Inventory)* | `1` |
| Warehouse *(under Delivery address → Inventory)* | `11` |

*\* Date placeholders — adjust relative to today. The expiration date must be in the future for the RFQ to accept bids; the requested receipt date should be after the expiration date.*

Click **OK**. The RFQ header record opens.

### Step 2 — Add the line item
In the **Lines** FastTab, click **Add line**:

| Field | Value |
|---|---|
| Item number | `PCB-CON-M12` |
| Quantity | `500` |
| Unit | `ea` |
| Site | `1` |
| Warehouse | `11` |

### Step 3 — Add Pacific Components as a solicitation vendor
Switch to the **Header** tab (next to **Lines** at the top of the RFQ form). Scroll down to the **Vendor** FastTab. Click **+ Add** — a new row appears inline. In the **Vendor account** column, select `USSEP-0002` (Pacific Components Ltd.). The **Name** and status columns fill automatically.

> **Note:** The Vendor FastTab controls who receives the RFQ. The vendor must exist as a local vendor in USMF (USSEP-0002, created in Setup A) and have **Collaboration activation = Active** — otherwise the send step will not deliver the RFQ to the portal.

### Step 4 — Send the RFQ
On the Action Pane, **Quotation** tab, click **Send**. Review the *Send request for quotation* confirmation dialog — Pacific Components Ltd. should appear in the vendor list. Click **OK** / **Send** to dispatch.

> ✅ **Result:** RFQ status changes to "Sent". Pacific Components Ltd. receives a notification that an RFQ is awaiting their response in the supplier portal.

## Part B — Submit Bid (Maria in supplier portal)

### Step 5 — Maria opens and responds to the RFQ
Maria signs in to the supplier portal. On the main navigation she selects **Requests for Quotation**. She finds the *TX-500 Program — M12 PCB Connector Sourcing Event* RFQ and opens it.

She clicks the option to reply to / edit the RFQ reply and enters her bid details:

| Field | Value Maria Enters |
|---|---|
| Unit price | `2.45` USD |
| Promised delivery date | `2026-09-10` (5 days early) |
| Valid until | `2026-08-31` |
| Vendor reference | `PCL-Q-2026-0089` |
| Notes / comments | `Price includes DDP shipping to Technova Site 1. Lead time: 14 calendar days. MOQ: 100 ea.` |

Maria submits the bid to Technova.

> **Note:** Because Supplier Engagement is in preview, exact supplier-portal button labels for RFQ replies may differ from those shown here. The RFQ bidding workflow follows standard vendor-collaboration behavior: the supplier opens the RFQ, enters pricing and delivery terms, and submits the reply.

> ✅ **Result:** Maria's bid appears in SCM on the RFQ replies list with Status = Received.

## Part C — Award the RFQ (Alex in SCM)

### Step 6 — Alex reviews the bid and accepts it
**Where:** Procurement and sourcing › Requests for quotations › Request for quotation replies

Open the RFQ reply for Pacific Components Ltd. Review the unit price (`USD 2.45`), delivery date, and notes. On the Action Pane click **Accept**. Confirm the dialog.

The system creates a purchase order or purchase agreement from the accepted bid, depending on the *Purchase type* set on the original RFQ.

> ✅ **Result:** RFQ awarded to Pacific Components Ltd. at USD 2.45/ea. The RFQ status changes to "Accepted" for the Pacific Components reply. A follow-on purchase order is generated (used in Lab 9).

### Step 7 — Verify supplier receives award notification
Confirm that the supplier notification email was sent to Maria Santos (Supplier Engagement uses cloud flows and email templates configured in Lab 2 to notify suppliers of RFQ activity). Maria should see the award confirmation in the supplier portal, where the RFQ status now shows **Accepted**.

> **Note:** If the notification email is not received, check that the Supplier Engagement cloud flows are turned on (Lab 2 Step 6) and that the service account mailbox is active (Lab 2 Step 2).
